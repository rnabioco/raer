# Provide working directory for raer example files.

Provide working directory for raer example files.

## Usage

``` r
raer_example(path)
```

## Arguments

- path:

  path to file

## Value

Character vector will path to an internal package file.

## Examples

``` r
raer_example("human.fasta")
#> [1] "/__w/_temp/Library/raer/extdata/human.fasta"
```
